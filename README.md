# 📖 Overview

This repository contains Java programs developed during the **Object-Oriented Programming Through Java Laboratory** course. The programs demonstrate the core principles of Object-Oriented Programming along with Java fundamentals, exception handling, multithreading, file handling, collections, generics, GUI programming, and database connectivity.

The repository is organized into weekly laboratory exercises, progressing from basic Java programming to advanced OOP concepts.

---

# 🎯 Objectives

- Learn Java programming fundamentals.
- Understand Object-Oriented Programming concepts.
- Implement inheritance, polymorphism, abstraction, and encapsulation.
- Practice exception handling and multithreading.
- Work with file handling and collections.
- Develop GUI applications using Swing/AWT.
- Connect Java applications with databases using JDBC.

# ⚙️ How to Run

Clone the repository

```bash
git clone https://github.com/manish24ts/ObjectOrientedProgrammingThroughJava.git
```

Move into the project

```bash
cd ObjectOrientedProgrammingThroughJava
```

Compile a Java program

```bash
javac ProgramName.java
```

Run the program

```bash
java ProgramName
```
